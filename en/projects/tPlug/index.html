tPlug – The intelligent multifunction switch

In this project, I designed and built tPlug, an intelligent multifunctional power switch that can automatically control electrical devices based on sensor readings, time schedules, and user-defined conditions.
The device combines a touchscreen interface with two Raspberry Pi microcontrollers, a motion sensor, and a temperature and humidity sensor. I developed the software in C++ to process sensor data, control the power supply, and provide an intuitive interface for configuring complex switching rules. The custom enclosure was designed in Blender and manufactured using a 3D printer.
The project combines electronics, embedded systems, software development, and 3D design to create a versatile smart home device that can automate everyday tasks and reduce unnecessary energy consumption.
