Rubic's Cube Robot

In this project, I designed and built a robot capable of autonomously solving a 3×3 Rubik’s Cube. Constructed using Fischertechnik components, the robot combines a pneumatic gripping arm with an electrically driven mechanism to manipulate the cube. I developed custom software in Python to calculate the solution and control the robot’s movements using a Fischertechnik ROBOTICS TXT Controller. The project combines mechanical engineering, robotics, and software development to demonstrate how hardware and algorithms can work together to solve a complex puzzle.
